# V7.8 Standalone Architecture

Owner command -> multilingual normalization -> local command router -> local AI/coding engine -> structural validation -> real compiler/runtime verification -> owner review -> optional final APK build/sign/install.

Research path: owner starts research -> Google/YouTube/another app opens -> Accessibility captures only exposed visible/public UI -> JSONL knowledge record -> owner may reference learned material in later coding prompts.

Self-upgrade path: build-time source snapshot bundled in APK -> owner requests self-upgrade -> snapshot extracted to private workspace -> local model generates proposed changes -> validation/real compiler gates -> owner approval -> final APK build/sign/install.
