# V7.8 Plugin / App Control System

- Plugin Center discovers installed launchable apps.
- Owner enables/disables control per package.
- Anamika can launch any discovered app label; known Google/YouTube searches also have direct intent/deep-link helpers.
- Accessibility control can operate only UI Android exposes: visible text/buttons, editable fields, scrolling, back and gestures.
- Deep App Blueprint remains available for owner-requested observable-function recording.
- Research mode can record visible/public text from owner-opened screens into a local knowledge session.
- Secure/DRM/banking/private app data, hidden backend logic, passwords and non-exposed functions are not bypassed.
