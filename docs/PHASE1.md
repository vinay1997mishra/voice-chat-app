# Phase 1 — GitHub-only Android Demo

## Goal

Produce an installable Android APK that demonstrates the core product flow without any paid server or external backend.

## Included now

- Demo-mode entry screen
- Home / featured room screen
- Room ID presentation
- 10-seat local room grid
- Join / leave seat simulation
- Mic mute / unmute simulation
- Local room chat
- Demo gifts with coin deduction
- Wallet balances and local transaction history
- Me / profile shortcuts
- Automated Flutter analyze, test and APK build in GitHub Actions

## Next GitHub-only increments

1. Room owner/admin controls and invite mode
2. 30-seat configuration and seat locking
3. Better profile editor and language selection
4. Gift catalog and combo quantities
5. Lucky Bag demo flow
6. VIP1–VIP11 demo catalog and cosmetic previews
7. Offline mini-game engine and first game
8. Owner/Admin panel frontend prototype
9. Backend/API source skeleton ready for later hosting

## Not real in Phase 1

Live voice, real accounts, multi-device realtime sync, payments, production wallet balances and cash payouts require external services and server-side infrastructure later.
