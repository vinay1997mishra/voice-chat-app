ANAMIKA AI V7.8 CINEMATIC MODEL SLOT

The app includes a procedural articulated dragon fallback, so cinematic scenes work offline
without downloading any model.

For true film-grade character detail, bundle a legally licensed rigged PBR dragon model during
the APK build. Recommended production asset requirements:
- GLB/glTF 2.0
- skeletal rig / skin
- flying, glide, landing, roar and fire-breath animation clips
- 2K/4K PBR textures (base color, normal, roughness/metallic, AO)
- LOD variants for mobile
- optimized triangle count appropriate for target phones

Movie-level realism comes from high-detail assets, materials, animation and device GPU power;
code alone cannot turn a low-poly fallback mesh into a feature-film creature.

V7.8 multilingual note:
- Voice recognition is not fixed to Hindi/English.
- UniversalLanguageRouter can use the bundled on-device model to normalize unfamiliar-language commands.
- For stronger multilingual coverage a future build may bundle a dedicated multilingual GGUF model; actual language accuracy depends on the chosen model and device speech service.
